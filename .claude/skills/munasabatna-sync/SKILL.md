# مزامنة أعراس munasabatna

استيراد الدعوات الجديدة المنشورة على `https://munasabatna.com/weddings/` إلى جدول `events`.

الدعوات صور بطاقات (مش نص)، فالخطوة الوحيدة اللي بتحتاج ذكاء هي قراءة البطاقة. باقي الخطوات سكربتات ثابتة.

## المتطلبات

- تكون بمجلد المشروع (اللي فيه `server.js` و `src/db/pool.js`).
- `.env` معبّى بإعدادات `DB_*` الصحيحة للسيرفر اللي بدك تكتب عليه.
- السكربتين `scripts/munasabatna-scan.js` و `scripts/munasabatna-insert.js` موجودين. إذا مش موجودين، اطلبهم من مالك المشروع — لا تكتبهم من راسك.

## الخطوات

### 1. افحص الجديد

```bash
node scripts/munasabatna-scan.js --download
```

بيرجّع JSON فيه `new_count` و `new_posters` و `download_dir`.

**إذا `new_count` = 0 → خلصت.** بلّغ "ما في دعوات جديدة" ووقّف. لا تكمّل ولا تخترع بيانات.

المقارنة مبنية على `poster_url` مش على الوقت — يعني إذا فات يوم أو وقع الكورن، التشغيل الجاي بيلحّق كل اللي انفات.

### 2. اقرأ كل بطاقة جديدة

افتح كل صورة نزلت بـ `download_dir` باستخدام أداة Read (فيها رؤية) واستخرج:

| الحقل | من وين | إذا مش مكتوب |
|---|---|---|
| `groom_name` | اسم العريس + اسم العائلة | **إلزامي** — إذا مش واضح تخطّى البطاقة وبلّغ عنها |
| `family_clan` | "أفراح آل ..." | `""` |
| `town` | البلدة المذكورة | احذف الحقل، لا تخمّن |
| `location_name` | القاعة / الحارة / المدخل | احذف الحقل |
| `event_date` | تاريخ الزفاف → `YYYY-MM-DD` | **إلزامي** |
| `youth_party_date` | حفل الشباب / عشاء البيوت / سهرة الدحية | `null` |
| `dinner_time` | "قبل صلاة المغرب" مثلاً — انسخها حرفياً | احذف الحقل |
| `host_phone` | رقم صاحب الفرح | `null` — **لا تاخذ رقم المصمّم** (بيكون مكتوب جنبه اسم استوديو أو DESIGN) |
| `poster_url` | رابط الصورة من `new_posters` | **إلزامي** |

**قاعدة صارمة: لا تخمّن البلدة أبداً.** كثير بطاقات ما بتذكر بلدة. إذا اسم العائلة معروف بمنطقة معينة هاد **مش** دليل. اترك الحقل فاضي والسكربت بيتصرّف.

البلدات المقبولة (أي إشي غيرها بينحوّل لـ `غير محدد`):
رهط · حورة · تل السبع · كسيفة · شقيب السلام · اللقية · عرعرة النقب · القرى والتجمعات

### 3. أدخل البيانات

اكتب اللي استخرجته بملف JSON — مصفوفة كائنات — وشغّل:

```bash
node scripts/munasabatna-insert.js < /tmp/new-events.json
```

السكربت بيفرض القواعد لحاله:
- بلدة مش بالقائمة → `غير محدد` والصف بصير `pending`
- ما في `location_name` → الصف بصير `pending`
- الإحداثيات بتتحسب من البلدة، مش من مدخلاتك
- تكرار على `poster_url` أو (`groom_name` + `event_date`) → بينتخطّى

### 4. بلّغ

اذكر بالضبط: كم انضاف، كم منهم `pending` وليش، وكم بطاقة تخطّيتها وليش. لا تقول "تمت المزامنة بنجاح" لحالها.

## أخطاء شائعة

- **لا تستعمل `POST /api/events`** لإدخال البيانات — بيرفض أي بلدة برّا القائمة، وبيخلي كل الصفوف الناقصة تفشل بدل ما تنحفظ كـ `pending`.
- **لا تعدّل الصفوف الموجودة** ولا السكيما.
- إذا `scan` فشل بخطأ شبكة، وقّف وبلّغ. لا تعيد المحاولة أكثر من مرتين ولا تدخّل بيانات ناقصة.
