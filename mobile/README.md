# تطبيق مناسبات النقب — فلاتر

واجهة موبايل تستهلك نفس خادم `../server` الذي تستهلكه واجهة الويب. **لا يحتوي هذا
المجلد أي منطق خادم** — كل البيانات عبر الـAPI.

## التشغيل

الخادم أولاً (من مجلد `../server`):

```bash
npm run dev
```

ثم التطبيق:

```bash
flutter run
```

عنوان الخادم الافتراضي: `http://localhost:3000` — وعلى **محاكي أندرويد** يتحوّل
تلقائياً إلى `http://10.0.2.2:3000` (المحاكي لا يرى `localhost` الخاص بالمضيف).

على **جهاز حقيقي** أو للإنتاج مرّر العنوان صراحةً:

```bash
flutter run --dart-define=API_BASE=http://192.168.1.20:3000
```

```bash
flutter build apk --release --dart-define=API_BASE=https://api.example.com
```

## البنية

```
lib/
  config.dart            عنوان الخادم، البلدات، أنواع التفاعل
  theme.dart             الهوية البصرية (أخضر داكن + ذهبي)، مطابقة للويب
  api/
    api_client.dart      HTTP، الرمز، وتحويل أخطاء الخادم إلى ApiException
    negev_api.dart       كل نقاط الـAPI في مكان واحد
  models/                Event, Story, MapPoint, NokootRecord, AppUser
  state/
    auth_store.dart      الجلسة (رمز 90 يوماً) محفوظة في SharedPreferences
    realtime.dart        Socket.IO — قنوات المناسبات والتبريكات
  screens/               المناسبات، الخريطة، إضافة، النقوط، الحساب
  widgets/               بطاقة المناسبة، حالات التحميل والخطأ
```

## قواعد

- **كل نداء عبر `api/negev_api.dart`** — لا `http` مباشر في الشاشات
- **الرمز يُرفق عند `auth: true` فقط.** لا تجعله افتراضياً: `POST /api/events`
  ينشر المناسبة فوراً إذا وصله رمز مدير، فإرفاقه في كل مكان يكسر طابور المراجعة
- **روابط الوسائط تصل مطلقة من الخادم** — لا تبنِ عنواناً في التطبيق
- البلدات في `config.dart` يجب أن تطابق `server/src/constants.js`، وإلا رفض الخادم الإرسال
- كل نص يراه المستخدم بالعربية

## الاختبارات

```bash
flutter test
```

تغطي تحليل النماذج ومعالجة أخطاء الخادم وسلوك إرفاق الرمز — بعميل HTTP وهمي،
فلا تحتاج خادماً يعمل.

## ملاحظات

- **تراخيص أندرويد**: لبناء APK نفّذ `flutter doctor --android-licenses` مرة واحدة
- **نسخة الويب**: صور المضيفين الخارجيين (مثل `munasabatna.com`) قد تُحجب بسياسة
  CORS في المتصفح. لا يحدث هذا على أندرويد و iOS — القيد خاص بالمتصفحات
