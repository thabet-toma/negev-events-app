## ما اكتمل

### الخادم

- `GET /api/news?limit=&offset=&general=` — عام بلا مصادقة. المحافظة من
  `X-Region` (أو محافظة الحساب، وإلا الافتراضية) عبر `regionIdForRequest`،
  والمنطقة تُشتقّ من **اسم المحافظة** ثم تُرسَل إلى المصدر كسلاگ عربي.
  الرد: `{ success, region_id, region_name, area, general, items[], has_more }`.
- `GET /api/news/:id` — نفس الحقول + `author_name` و`body_text`؛ غير موجود ← 404.
- `server/src/services/news.service.js`: النداء، التطبيع، كاش `Map` (٥ دقائق،
  ومفتاحه `area|limit|offset`)، وخدمة آخر نسخة ناجحة حتى ساعة عند سقوط المصدر،
  و502 عربي بلا كاش. لا SQL ولا `req`/`res`.
- `NEWS_AREA_BY_REGION_NAME` في `constants.js`: «النقب»→`النقب`،
  «محافظة طولكرم»→`طولكرم`، «اللد والرملة ويافا»→`اللد-والرملة-ويافا`؛ اسم غير
  معروف ← `general`. **المفاتيح عربية لأن المصدر يردّ `zone_not_found` للاتينية.**
- **إصلاح اليوم:** خبر محذوف كان يخرج 502 لأن المصدر يردّ HTTP 404؛ صار 404
  «الخبر غير موجود» (و`{ok:false,error:not_found}` بحالة 200 أيضاً).
- **تنقية نصّ المصدر (بعد التحقّق البصري):** مقتطف المصدر ونصّه يصلهما مخلوطين
  بزخرفة صفحة كترا — عدّاد القسم واسمه («0 اخبار محلية …»)، ثم عنوان الخبر
  مرّة ثانية، وسطر «ك ا كل العرب … نُشر: … حجم الخط A- A+ ✓تم النسخ».
  ثلاثة حرّاس في `news.service.js` وحدها: `withoutSourcePrefix` (يقطع بادئة
  قصيرة بلا نقطة، ٤٠ حرفاً فأقصى)، `excerptFor` (يُسقط العنوان المكرّر، ويُسقط
  المقتطف كاملاً `null` إن كان مسحوقاً بأزرار الموقع)، و`bodyTextFor` (يُسقط
  سطور الزخرفة من النصّ ويُبقي ما حولها). البادئة تُقطع فقط حين تكون قصيرة وبلا
  جملة — فلا يُقتطع خبر حقيقي لمجرد ورود عنوانه في وسطه.

### الويب (`web/`)

- الشريط السفلي أربع وجهات: المناسبات · خدماتنا · خدمات الأعراس · حسابي،
  وكبستان عائمتان فوقه: «أضف عرسك» (تفتح `openAddEventModal`) و«أضف خدمتك»
  (تفتح `openSubmitServiceModal`). لا زرّ «＋» عائم.
- «حسابي» فيه بطاقات وصول سريع: دفتر النقوط، الخريطة، قائمتي (مع عدّاد اليوم)،
  وشارة الشريط `myListNavBadge` على أيقونة «حسابي».
- `tabOurServices`: ثلاث بطاقات ثابتة بالترتيب — آخر خبر (تفتح القارئ)،
  متاجرنا (`https://kolshee.ktra-pro.tech/`)، K.T.R.A ERP (`https://ktra-pro.tech/`).
- `#newsScreen`: طبقة ملء الشاشة، ٥٠ خبراً، «المزيد»، كروت بصورة/شارة عاجل/قسم/
  وقت نسبي، تفصيل داخلي بالنصّ الكامل + «افتح على كترا»، حالات تحميل/خطأ/فراغ،
  وإغلاق بـ× وبـEscape. النداءات عبر `apiFetch` وحدها.

### مصدر الأخبار — منصة كترا (منصة مستقلة، بلا تعديل منّا)

الواجهة موجودة حياً على `https://radio.ktra-pro.tech/api/news.php`:

| الطلب | الرد |
|---|---|
| `?zones=1` | `{ ok, zones: [{ id, name, slug, count }] }` — اليوم: النقب (10)، اللد والرملة ويافا (11)، طولكرم (12) |
| `?area=<slug أو name>&limit=&offset=` | `{ ok, area, count, has_more, items[] }` |
| `?area=general` (أو بلا `area`) | أخبار الأب «أخبار محلية» (id=1) |
| `?id=<id>` | `{ ok, item: { id, title, image, url, published_at, author_name, body_text, category } }` |
| منطقة مجهولة / خبر غير موجود | 404 بنصّ عربي |

- السلاگات عربية: `النقب`، `طولكرم`، `اللد-والرملة-ويافا`.
- **إضافة منطقة مستقبلاً**: تُضاف كتصنيف فرعي تحت «أخبار محلية» من لوحة كترا
  (محتوى، بلا كود)، ثم يُضاف سطر واحد في `NEWS_AREA_BY_REGION_NAME` عندنا إن
  اختلف الاسم عن اسم محافظتنا.
- الأقسام الفرعية اليوم: النقب 3 أخبار، اللد والرملة ويافا 1، طولكرم 0، والباقي
  على الأب «أخبار محلية» (38) — لذلك أي محافظة بلا أخبار تُظهر «لا أخبار
  لمحافظتك بعد» + زرّ «أخبار محلية عامة».

## التحقّق البصري — تمّ بمتصفّح حقيقي (2026-11-02)

`jsdom` بلا محرّك تخطيط، فالتخطيط فُحص بـ**Chrome headless عبر CDP** على نسخة
محلية كاملة: خادمنا على `:3000` بقاعدة `negev_visual_check`، و`web/serve.js` على
`:8080`، والمصدر **كترا الحي** لا خادم وهمي. الصور في
`docs/handoff-shots-services-news-2026-11/` (نصف القياس، ١٨٠٠ عرضاً كاملة).

النتيجة، كما قيست وكما تُرى في الصور:

- الشريط أربع وجهات بأيقوناتها ونصوصها، «المناسبات» مشتعلة افتراضياً؛
  «خدماتنا» تشتعل عند `openOurServices()`. لا زرّ «＋» عائم في الصفحة.
- الكبستان فوق الشريط متمركزتان ولا تتداخلان معه (`capsules.bottom ≤ bar.top`).
- ٤٣٠px و٣٦٠px: `scrollWidth == innerWidth` (لا تمرير أفقي)، ولا نصّ مقصوص في
  أي زرّ ولا كبسولة، والشريط ٦٩px.
- «خدماتنا»: ثلاث بطاقات بعرض كامل مرتّبة رأسياً — آخر خبر · متاجرنا · K.T.R.A ERP.
- «آخر خبر»: ٣ أخبار حيّة من منطقة النقب بصورها وأسمائها ووقتها النسبي
  («قبل 3 ساعات»)، ثم التفصيل بنصّ فقرات؛ والوجه العام يعرض وسم «عامة» في
  الهيدر وأخبار «أخبار محلية» (٣٨ خبراً).
- **صفر أخطاء** في `Runtime.exceptionThrown` و`console.error` و`log.entries`،
  وصفر طلبات شبكة فاشلة في الجلسة كلها.

السكربتات المؤقتة في `%TEMP%\negev-visual\` (`shoot.js` للصور، `probe.js` لبنية
DOM) — خارج المستودع عمداً، تُعاد بنسخ المسار نفسه إن لزم.

## ما لم يُتحقَّق منه

- **الموبايل على جهاز**: `flutter test` يبني الشاشات في نافذة اختبار، لا على
  هاتف حقيقي؛ الشكل النهائي لشاشة الأخبار ووسم «عامة» فيها لم يُعاين بصرياً.
- **بيانات حيّة داخل البوابة**: اختبارات الخادم تستخدم خادماً وهمياً؛ الاتصال
  الحقيقي بكترا تحقّق بمتصفّح وخادم محليَّين (`curl` + الصور أعلاه)، لا داخل
  `npm test`.

## الخطوة التالية — النشر (قرار المالك، لم يُتخذ)

الويب وحده لا يكفي: المسار الجديد في الخادم، وخادم الإنتاج يسحب `main` لا
`version2`. فنشرُ هذه الميزة يبدأ بنقل الفرع كله:

```bash
# على جهازك — version2 تقدّم مباشر على main، فلا تعارض
git checkout main && git pull origin main
git log --oneline origin/main..version2      # ٢٦ التزاماً: اقرأها قبل الإصدار
git merge --ff-only version2
git push origin main

# على الخادم
cd /root/munasbat/app && git pull origin main
docker compose build app && docker compose up -d app     # مسار /api/news الجديد
docker exec negev_events_web nginx -s reload             # ملفات web/ مربوطة كـvolume
curl -fsS "$PUBLIC_URL/api/news?limit=1" -H 'X-Region: 1'
```

- **بلا رفع أي APK** وبلا تغيير `APP_LATEST_VERSION` (تجربة سوق بلاي قائمة).
- قبل النشر: خضرة البوّابتين + قراءة `git diff` كاملاً.
- الخادم الإنتاجي يقرأ `KATRA_NEWS_BASE_URL` (الافتراضي
  `https://radio.ktra-pro.tech`)، و`KATRA_NEWS_CACHE_TTL_MS` (افتراضي 300000)،
  و`KATRA_NEWS_TIMEOUT_MS` (افتراضي 5000) — لا حاجة لإضافتها.
- **التقدّم المباشر يعني إصدار ٢٦ التزاماً معاً** لا هذه الميزة وحدها: الألبومات
  والفيديوهات وبطاقة الدخول وتعديلات فيسبوك بينها. راجع القائمة قبل الدمج.
