**والثلاثة مستقلّة فعلاً — رتّبها كما شئت.** ‏`negev_api.dart` لم يُمَسّ في هذا

⚠️ **القيد الوحيد داخل الجزء الثالث نفسه:** ملف الـAPK يجب أن يصل مكانه **قبل**
رفع `APP_LATEST_VERSION`. عكسُ الترتيب يجعل التطبيقات القائمة ترى تحديثاً
وتنزّل **الملف القديم**.

## ما الذي يتغيّر ولماذا

### ١. اسم المنتج تغيّر

«مناسبات النقب» صار **«أعراسنا»**، والاسم القديم صار **السطر الوصفي تحته**. لا
نصّ جديد اختُرع، وآلاف الروابط المنشورة في مجموعات واتساب تُظهر اسماً يعرفه الناس.

**والأهمّ:** الاسم صار يتبع نغمة المناسبة كما يتبعها اللون. `shareTheme` كان يختار
اللوحة من `occasion_type_tone` **ولا يختارها من اسم النوع أبداً** — بينما نصّ ثابت
في الكود كان يتجاهل القاعدة نفسها، فبطاقة العزاء تحمل علامة عرس. كل لوحة صارت
تحمل `wordmark` خاصّاً بها.

> **على سطح عزاء لا تظهر كلمة «أعراسنا» إطلاقاً.** إن رأيتها بعد النشر على مناسبة
> عزاء فهذا **عطل يستوجب التراجع**، لا مسألة ذوق.

**ما لم يُمَسّ عمداً** — لا تُغيّره «للاتّساق»:
`applicationId` · `CFBundleName` · مفتاحا `negev_token` و `negev_user` في
`localStorage` (تغييرهما يُخرج كل مستخدمي الويب من حساباتهم بلا إشعار) · اسم حزمة
فلاتر · أسماء الجداول والأعمدة · أسماء أحداث القياس · الدومين.

### ٢. العلامة أُعيد رسمها، ولها الآن طبقتان

بيت شَعَر واطئ متهدّل الظهر تحت انفجار ضوء من صاريه، يطوّقه إكليل لمبات مغلق
يُقرأ خاتماً.

مُعرَّفة **مرة واحدة** في `server/src/utils/brandMark.js` — لا في `scripts/` بعد
الآن — ومنها يولّد `server/scripts/brand-icons.js` كل الملفات، **والنقطي والمتّجه
من نفس التعريف**. الطبقة تُختار **بالغرض لا بمقاس الملف**: كل ما يعرضه النظام
أيقونةَ تطبيق يأخذ المبسَّطة، لأن ملف ١٨٠px يظهر على الآيفون بنحو ٦٠px.

⚠️ **لا تحرّر أي PNG ولا SVG بيدك.** عدّل الهندسة وأعد تشغيل المولّد.

### ٣. محرّر قصّ عند رفع الملصق — في العميلين

مستطيل حرّ الأبعاد، اختياري، سقفه ١٦٠٠px. **العميل يقصّ والخادم لا يتغيّر بحرف** —
لا عمود جديد ولا معالجة صور خادمية.

**عقد عرض الملصق (#53) لم يُمَسّ**: أسطح المسح لا تزال تقصّ من الأعلى. المستطيل
يقول *ما هي الصورة*، لا *كيف تُؤطَّر على كل سطح*.

### ٤. بطاقة المشاركة وصفحة الرابط

إطار مزدوج يأخذ لونه من النغمة (ذهبي للفرح، زيتيّ للعزاء — **لا يختفي أبداً**)،
ولون إضافي من `occasion_types.color` نفسه. والصفحة اكتسبت حجّة وزرّاً ثانياً وخطّها
العربي.

### ٥. عطلان مُصلَحان لم يكونا في الطلب

- **صاحب الآيفون كان يُعطى ملف APK** — الزرّ الوحيد يحوّل إلى بناء أندرويد بلا فحص
  منصّة، والنقرة تُحتسب تحميلاً ناجحاً. صار زرّان.
- **زرّ إغلاق إرشاد التثبيت لم يكن يُغلق شيئاً**، ونفس السطر كان يُظهر الإرشاد
  **لكل زائر على كل منصّة** لا للآيفون وحده.

### ٦. توسيع واحد في ترويسة الأمان — يُرى ولا يمرّ

صفحة `/e/:id` كانت ممنوعة من خطّها العربي: ترويستها `default-src 'none'` بلا أي
مصدر خطّ، فتُقرأ بخطّ النظام بينما البطاقة **داخلها** مرسومة بخطّ Cairo.

الترويسة الآن:

```
default-src 'none'; img-src *; style-src 'unsafe-inline'; font-src 'self'
```

**توجيه واحد بالضبط، `'self'` لا `*`، ولا `script-src` بأي حال.** وملفّا Cairo
يُخدَمان من مسار الأصول القائم، ورخصة OFL معهما.

## قبل أي شيء — تحقّق ممّا هو حيّ فعلاً

لا تُبلّغ عن حالة النشر من الذاكرة. أمرٌ واحد يكفي:

```bash
ssh -i ~/.ssh/hostenger2/id_ed25519 root@munasbat.ktra-pro.tech \
  'cd /root/munasbat/app && git log --oneline -1 && \
   docker exec negev_events_app grep -c wordmark /app/src/utils/shareTheme.js; \
   curl -s localhost:3100/api/app/version'
```

`/app/src` يأتي من **الصورة المبنيّة** (‏`uploads` و `downloads` وحدهما mounts)، فوجود
`wordmark` داخل الحاوية هو ما يثبت أن الصورة أُعيد بناؤها — `git pull` وحده لا يغيّر
شيئاً للخادم. أما `web/` فعكسه تماماً: **bind mount حيّ**، فالسحب يسري فوراً ولا
يتأخّر إلا كاش المتصفّح.

## الجزء الأول — الويب (فوري، بلا إعادة تشغيل)

```bash
ssh -i ~/.ssh/hostenger2/id_ed25519 root@munasbat.ktra-pro.tech
cd /root/munasbat/app
git fetch origin && git checkout main && git pull
```

**تحقّق في المتصفّح بعد تفريغ الكاش (‏`Ctrl+Shift+R`):**

1. الترويسة تقول **«أعراسنا»** وتحتها «مناسبات النقب»، وشعار الخيمة **الجديد**
   (بأشعّة وطوق لمبات) — لا الخيمة القديمة المسطّحة.
2. **إرشاد التثبيت لا يظهر على كروم/ويندوز إطلاقاً.** كان يظهر للجميع؛ إن ظهر
   فالنشر لم يصل.
3. ادخل نموذج النشر، اختر ملصقاً: **يجب أن يظهر محرّر قصّ** بمستطيل ومقابض.
4. تبويب الشبكة: `icon.svg` و `favicon-32.png` بتاريخ اليوم.

## الجزء الثاني — الخادم (يحتاج إعادة بناء)

> ⚠️ **الترحيلات تعمل تلقائياً عند إقلاع الحاوية.** خذ النسخة الاحتياطية **قبل**
> إعادة التشغيل لا بعدها.
>
> **هذا الإصدار لا يحمل أي تغيير في المخطط** — لا `ALTER` ولا خطوة ترحيل جديدة
> ولا عمود. النسخة الاحتياطية احتياط لا علاج.

```bash
cd /root/munasbat/app
docker exec negev_events_mysql mysqldump -u root -p"$MYSQL_ROOT_PASSWORD" negev_events \
  > ~/backup-$(date +%F-%H%M).sql
ls -lh ~/backup-*.sql | tail -1

docker compose build app && docker compose up -d app
docker compose logs --tail 40 app
```

**تحقّق — والأول منها هو البوّابة:**

```bash
# ١) صفحة عرس: تحمل «أعراسنا»
curl -s localhost:3100/e/<ID_عرس> | grep -o 'og:site_name[^>]*'

# ٢) صفحة عزاء: صفر ظهور لـ«أعراسنا» — لا نقاش
curl -s localhost:3100/e/<ID_عزاء> | grep -c 'أعراسنا'   # يجب أن يطبع 0

# ٣) الترويسة توسّعت بتوجيه واحد فقط
curl -sI localhost:3100/e/<ID> | grep -i content-security-policy

# ٤) الخطّ يُخدَم فعلاً
curl -sI localhost:3100/e/assets/Cairo-Regular.woff2 | head -3

# ٥) البطاقة تُولَّد وتحت السقف
curl -s localhost:3100/e/<ID>/card.jpg -o /tmp/c.jpg && ls -l /tmp/c.jpg
```

الخطوة **٢** إن طبعت غير الصفر فالنشر **يُتراجَع عنه**.
الخطوة **٥** يجب أن تكون **أقلّ من ‎600,000 بايت**؛ فوقها يُسقِط واتساب المعاينة.

### تخبئة البطاقات — لا تحتاج تدخّلاً

البطاقات مخبَّأة بمفتاح `(معرّف المناسبة، updated_at)`، وتغيير **التصميم** لا يغيّر
`updated_at` — فكان كل كرت قائم سيبقى بالتصميم القديم ويبدو النشر فاشلاً.
**عولج في الكود:** المفتاح صار يحمل `CARD_DESIGN_VERSION`، فكل البطاقات تُستبدَل
تلقائياً وتُنظَّف القديمة. **لا تُفرّغ `server/cache/share-cards/` يدوياً.**

## الجزء الثالث — إصدار التطبيق ‎1.5.0+7

> **لا تبدأ قبل أن تنجح كل فحوص الجزء الثاني.**

يحمل هذا الإصدار: الاسم الجديد على أيقونة الهاتف · العلامة الجديدة · **ومحرّر
القصّ على الموبايل**. والأخير يجلب حزمة أصلية جديدة (`image_cropper`)، فهذا
**ليس بناءً روتينياً**.

### محلياً

```bash
cd mobile
# ١) ارفع النسخة في pubspec.yaml إلى:  version: 1.5.0+7
C:/Users/asus/flutter/bin/flutter.bat pub get       # إلزامي: حزمة جديدة
C:/Users/asus/flutter/bin/flutter.bat analyze       # يجب: No issues found
C:/Users/asus/flutter/bin/flutter.bat test          # يجب: 42 ناجحاً
C:/Users/asus/flutter/bin/flutter.bat build apk --release
```

⚠️ **افحص القصّ يدوياً على جهاز حقيقي قبل الرفع.** `image_cropper` يفتح شاشة
أصلية لا يبلغها `flutter test`، وإن نقص تسجيل `UCropActivity` فالتطبيق **يُبنى
بنجاح ثم ينهار عند أول قصّ**. الخطوات: اختر دعوة **طولية** → اقصّها → انشر →
تأكّد أن القصّ هو ما وصل الكرت، وأن شاشة القصّ **بالعربية**.

### الرفع

```bash
scp -i ~/.ssh/hostenger2/id_ed25519 \
  build/app/outputs/flutter-apk/app-release.apk \
  root@munasbat.ktra-pro.tech:/tmp/negev-events.apk
```

### على السيرفر

```bash
cd /root/munasbat/app

# ١) اقرأ قبل أن تحرّك — سلسلة && تنفّذ mv ثم تفشل على مسار خاطئ،
#    فينتهي بك APK جديد ونسخة قديمة، وهو «نصف الإصدار» بعينه.
grep -n '^APP_LATEST_VERSION' .env        # لا تتقدّم إن لم يطبع شيئاً

# ٢) حرّك الملف
cp server/downloads/negev-events.apk ~/apk-backup-$(date +%F).apk
mv /tmp/negev-events.apk server/downloads/negev-events.apk
chmod 644 server/downloads/negev-events.apk

# ٣) ارفع النسخة وأعد التشغيل
sed -i 's/^APP_LATEST_VERSION=.*/APP_LATEST_VERSION=1.5.0/' .env
grep -n '^APP_LATEST_VERSION' .env        # يجب أن يقول 1.5.0
docker compose up -d app
```

> **رفع الملف نصف الإصدار فقط.** حتى يُنقل فوق
> `server/downloads/negev-events.apk` **و** تُرفع `APP_LATEST_VERSION` مع إعادة
> تشغيل، يظلّ الموقع يخدم الـAPK القديم بصمت.

```bash
curl -sI https://munasbat.ktra-pro.tech/downloads/negev-events.apk | grep -i last-modified
curl -s  https://munasbat.ktra-pro.tech/api/app/version
```
