# برومت النشر — كرت المعاينة المولَّد (الخادم فقط)

نشرٌ للخادم وحده. **لا APK جديد ولا ترحيل قاعدة بيانات ولا تعديل nginx** —
التطبيق يبقى `1.3.0+5` كما هو، ومسار `/e/` مضبوط أصلاً منذ نشر 1.3.0.

| | |
|---|---|
| السيرفر | `root@munasbat.ktra-pro.tech` · مفتاح `~/.ssh/hostenger2/id_ed25519` (المسار مجلد، والمفتاح داخله) |
| مسار التطبيق | `/root/munasbat/app` |
| من | `b95fea5` ← **إلى `main` بعد دمج كرت المعاينة** |

## ما الذي يتغيّر ولماذا

معاينة الرابط على واتساب وفيسبوك كانت **تمرّر ملصق المناسبة نفسه**. الملصق
الحقيقي على الإنتاج **1080×2340** — لقطة شاشة طولية — بينما خانة المعاينة نحو
‏1.91:1، فالزاحف إمّا يرمي الصورة أو يقصّ منها شريطاً أفقياً بلا معنى. وهذا
الشريط يحمل **التاريخ والمكان المطبوعَين على الملصق**، أي عكس ما وُجدت هذه
الصفحة لأجله بالضبط.

صار الخادم **يرسم كرته**: ‏1200×630، خلفيته الملصق مطموساً ومعتّماً (الطمس هو ما
يُبقي التاريخ غير مقروء، لا مجرّد زينة)، وعليه نوع المناسبة وأسماء أصحابها.
والنوع صار **يتصدّر** نصّ المعاينة بدل حقل `title` الحرّ الذي يكتب فيه الناس أي
شيء — على صفّ حقيقي كان اسم بلدة.

## ⚠️ نقطة الخطر الوحيدة: مكتبة الرسم

أُضيفت `@napi-rs/canvas`. لها **ثنائي musl جاهز** يناسب `node:20-alpine`، فلا
حاجة لمترجم ولا لتعديل `Dockerfile` — **لكن هذا لم يُجرَّب داخل الحاوية بعد**
(جهاز التطوير ويندوز). أول `docker compose build` هو الاختبار الحقيقي.

**إن فشل البناء فلا ضرر:** الحاوية القديمة تبقى تعمل كما هي. **قف وأبلغ بنصّ
الخطأ، ولا تحاول تثبيت حزم بناء داخل الصورة باجتهادك.**

## ١. النسخة الاحتياطية

لا ترحيل في هذا النشر، لكن `RUN_MIGRATIONS` يعمل عند كل إقلاع، والقاعدة الأمنية
تبقى: النسخة قبل إعادة التشغيل لا بعدها.

```bash
cd /root/munasbat/app
docker exec negev_events_mysql sh -c \
  'mysqldump -u root -p"$MYSQL_ROOT_PASSWORD" --single-transaction --routines negev_events' \
  > ~/negev-backup-before-sharecard.sql
tail -1 ~/negev-backup-before-sharecard.sql
```

السطر الأخير يجب أن يكون `-- Dump completed`. إن لم يكن، **قف وأبلغ**.

## ٣. تحقّق — الستة كلها

استعمل رقم مناسبة **معتمدة** حقيقياً؛ خذه من:
`curl -s "https://munasbat.ktra-pro.tech/api/events?limit=1"`

```bash
ID=<رقم مناسبة معتمدة>

# 1. الكرت يُخدَم صورة PNG
curl -sI "https://munasbat.ktra-pro.tech/e/$ID/card.png" | grep -iE "^HTTP/|^content-type|^content-length"

# 2. وأبعاده 1200x630 فعلاً (تُقرأ من بايتات PNG لا من الترويسة)
curl -s "https://munasbat.ktra-pro.tech/e/$ID/card.png" -o /tmp/card.png
python3 -c "import struct;d=open('/tmp/card.png','rb').read();print('PNG' if d[:8]==b'\x89PNG\r\n\x1a\n' else 'NOT PNG', struct.unpack('>II', d[16:24]))"

# 3. الصفحة تشير إلى الكرت لا إلى الملصق
curl -s "https://munasbat.ktra-pro.tech/e/$ID" | grep -oE 'property="og:(image|image:width|image:height|title)" content="[^"]*"'

# 4. الطلب الثاني يأتي من المحفوظ (لا يُعاد الرسم)
docker exec negev_events_app ls -l /app/cache/share-cards | head

# 5. مناسبة معلَّقة أو غير موجودة ⇒ 404 للكرت أيضاً
curl -s -o /dev/null -w "%{http_code}\n" "https://munasbat.ktra-pro.tech/e/999999999/card.png"

# 6. لم ينكسر شيء قائم
curl -s "https://munasbat.ktra-pro.tech/api/services/providers" | grep -c phone
curl -s -o /dev/null -w "%{http_code}\n" https://munasbat.ktra-pro.tech/
```

المتوقَّع: (1) `200` و`image/png` · (2) `PNG (1200, 630)` · (3) `og:image` ينتهي
بـ`/card.png` **وog:title يبدأ بنوع المناسبة** (مثل «عرس …») لا باسم بلدة ·
(4) ملف واحد على الأقل باسم `<id>-<رقم>.png` · (5) `404` · (6) **صفر** و`200`.

🛑 **إن جاء (6) الأول بغير الصفر — أوقف وأبلغ فوراً**؛ يعني أرقام مزوّدين تُبَثّ
في استجابة عامة، وهو ما بُني حارسه كله ليمنعه.

إن جاء (1) بـ`302` بدل `200`، فالرسم فشل والخادم سقط إلى الملصق القديم — **هذا
سقوط آمن مقصود لا انهيار**، لكنه يعني أن المكتبة لم تعمل داخل الحاوية.
**أبلغ بنصّ الخطأ من `docker compose logs app | grep shareCard`.**

## ٤. الفحص البصري — وهو الغاية من النشر كله

⚠️ **واتساب وفيسبوك يخزّنان المعاينة لكل رابط.** رابط شاركته قبل هذا النشر
سيظل يعرض المعاينة القديمة، وهذا **ليس فشلاً في النشر**:

- **اختبر برابط مناسبة لم تُشارَك من قبل**، أو
- حدّث الذاكرة يدوياً على
  [أداة فيسبوك](https://developers.facebook.com/tools/debug/) بلصق الرابط وضغط
  «Scrape Again».

ثم أرسل الرابط في محادثة واتساب حقيقية وتأكّد أن **الصورة تظهر**، وأن **نوع
المناسبة يظهر في السطر**، وأن **لا تاريخ ولا مكان مقروءين** في الصورة.

## ما لا تفعله

- **لا تشغّل `npm test` على الإنتاج** — يرفض العمل عند `NODE_ENV=production`
  (‏ADR-0005) وهو يكتب بيانات تجريبية.
- **لا تُضِف حزم بناء إلى `Dockerfile`** لتُرضي المكتبة. إن لم يعمل الثنائي
  الجاهز فالقرار ليس لك.
- **لا تمسح `/app/cache/share-cards` يدوياً** — يُبنى وحده، ويُخلي القديم عند كل
  تعديل مناسبة.
