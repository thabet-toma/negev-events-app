# مرجع العلامة البصري

**هذه الصور ليست أصل العلامة.** الأصل هو `buildMarkParts` في
`server/src/utils/brandMark.js` — إحداثيات، لا صور. وكل ملفات الأيقونات مولَّدة
منها بـ`node scripts/brand-icons.js` من داخل `server/`.

## لماذا يوجد هذا المجلد

العلامة كودٌ الآن، ومَن يفتح `brandMark.js` يرى أرقاماً لا شكلاً. تغييرُ رقم
واحد يقلب الخيمة قبّةً أو جبلاً **وكل الاختبارات تبقى خضراء** — لأنها تفحص
المنطقة الآمنة والوضوح عند ٤٨px والفرق بين الطبقتين، **لا الشكل**.

هذا حدث فعلاً ثلاث مرات أثناء بناء العلامة: قمّة حادّة، ثم قبّة، ثم الصواب. وكل
مرة انكشفت **بالنظر إلى الصورة**، لا بسقوط اختبار.

## الملفات

| الملف | ما هو |
|---|---|
| `mark-approved.png` | الشكل الذي اعتمده صاحب المنتج — **المرجع الحاكم** |
| `mark-current-from-code.png` | ما يرسمه الكود الآن، مولَّد للمقارنة |

## متى تستعملهما

**بعد أي تعديل على الهندسة**، أعد توليد `mark-current-from-code.png` وقارنه
بـ`mark-approved.png` بعينك. إن ابتعد الشكل فقد انحرف الرسم، مهما كانت
الاختبارات خضراء.

إعادة التوليد:

```
node scripts/brand-icons.js        # من داخل server/
```
