# برومت التنصيب — مزامنة يومية الساعة 12 ظهراً

انسخ كل اللي بعد السطر وارساله للوكيل على سيرفر `munasbat.ktra-pro.tech`.
بينصّب المهارة + الكورن مرة وحدة، وبعدها بتشتغل لحالها كل يوم.

---

## المهمة

عندك مشروع `negev_events_app` (Node + Express + MySQL). بدي تركّب مزامنة يومية بتسحب دعوات الأعراس الجديدة من `https://munasabatna.com/weddings/` وتضيفها على جدول `events`.

نفّذ الخطوات بالترتيب:

### 1. تأكد إن ملفات المزامنة موجودة

لازم يكونوا موجودين بالمشروع:

- `scripts/munasabatna-scan.js`
- `scripts/munasabatna-insert.js`
- `.claude/skills/munasabatna-sync/SKILL.md`

إذا ناقصين، اطلبهم من مالك المشروع (موجودين بالريبو المحلي عنده). **لا تكتبهم من راسك.**

### 2. جرّبهم قبل الكورن

```bash
cd /path/to/negev_events_app
node scripts/munasabatna-scan.js
```

لازم يرجّع JSON فيه `on_page` و `new_count`. إذا طلع خطأ اتصال بقاعدة البيانات، صلّح `.env` (`DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`) قبل ما تكمّل.

بعدين شغّل المهارة كاملة مرة يدوياً وشوف النتيجة:

```bash
claude -p "/munasabatna-sync"
```

### 3. ركّب الكورن — كل يوم 12:00 ظهراً

```bash
crontab -e
```

وضيف هالسطر (بدّل المسار بالمسار الحقيقي):

```
0 12 * * * cd /path/to/negev_events_app && /usr/local/bin/claude -p "/munasabatna-sync" >> /var/log/munasabatna-sync.log 2>&1
```

نقاط لازم تنتبه إلها:

- **المسار الكامل لـ `claude`** إلزامي — الكورن ما بيقرأ `PATH` تبعك. اطلعه بـ `which claude`.
- **تأكد من توقيت السيرفر** بـ `timedatectl` أو `date`. إذا السيرفر على UTC والمطلوب 12 ظهراً بتوقيت فلسطين، عدّل الساعة بالكورن أو اضبط المنطقة الزمنية.
- **الكورن ما بيقرأ `.env` تلقائياً** — السكربتات بتحمّله لحالها عبر `dotenv` من مجلد المشروع، عشان هيك `cd` بأول السطر ضروري.

### 4. تحقق إنه اشتغل

بعد أول تشغيل تلقائي:

```bash
tail -50 /var/log/munasabatna-sync.log
```

ولازم تفحص قاعدة البيانات:

```sql
SELECT id, groom_name, town, event_date, status, created_at
FROM events ORDER BY created_at DESC LIMIT 10;
```

## قواعد مهمة

- **آلية كشف الجديد مبنية على `poster_url` مش على نافذة زمنية.** يعني إذا وقع السيرفر أو فشل تشغيل، التشغيل الجاي بيلحّق كل اللي انفات لحاله. لا تحوّلها لفلتر 24 ساعة.
- **الدعوات اللي بطاقتها ما بتذكر البلدة بتنحفظ `pending`** مع بلدة `غير محدد`. هاد مقصود مش خلل — الأدمن بكمّلها من `/admin.html`. لا تخمّن بلدة عشان "تنضّف" الأرقام.
- **لا تعدّل السكيما** ولا الصفوف الموجودة.

## بلّغني بعد ما تخلص

اذكر: مسار `claude` اللي استعملته، سطر الكورن الفعلي، المنطقة الزمنية للسيرفر، ونتيجة التشغيل اليدوي (كم دعوة انضافت وكم `pending`).
